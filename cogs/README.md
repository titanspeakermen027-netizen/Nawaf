# Nawaf Cogs

كل نظام مستقل في Cog خاص به، مع قاعدة SQLite مشتركة في `database.py`.

- `messages.py`: إرسال رسائل إلى روم محدد وتحديد روم الإعلانات.
- `tickets.py`: فتح التذاكر وإغلاقها وتقييمها مع ملاحظة.
- `leveling.py`: XP والمستويات.
- `applications.py`: التقديمات وقبول/رفض الطلبات.
- `announcements.py`: الإعلانات.
- `dhikr.py`: الأذكار التلقائية.
- `economy.py`: العملة الخاصة بالسيرفر والتحويلات.
- `shop.py`: المتجر والمنتجات والمخزون والطلبات والشراء.
- `config.py`: عرض إعدادات السيرفر.
- `permissions.py`: معالجة أخطاء الصلاحيات.
- `health.py`: فحص حالة البوت.
